# Saborê - Aplicativo de Receitas

## Como visualizar o projeto

### 1. Requisitos
- Android Studio instalado.
- Flutter SDK configurado.
- Emulador Android ou dispositivo físico conectado.

### 2. Abrir o projeto
1. Abra o Android Studio.
2. Selecione **Open**.
3. Localize e selecione a pasta do projeto Saborê.
4. Aguarde o Android Studio carregar os arquivos e as dependências.

### 3. Executar o aplicativo
1. Inicie um emulador Android ou conecte um dispositivo físico.
2. Selecione o dispositivo na barra superior do Android Studio.
3. Clique no botão **Run** (ícone de execução).
4. Aguarde a compilação e a abertura do aplicativo.

### 4. Visualizar a estrutura dos widgets
1. Com o aplicativo em execução, acesse **View → Tool Windows → Flutter Inspector**.
2. Abra a árvore de widgets para visualizar a hierarquia dos elementos que compõem as telas.

## Sobre o projeto

O Saborê é um aplicativo de receitas desenvolvido utilizando Flutter e Dart. O aplicativo utiliza a API DummyJSON para carregar e pesquisar receitas.
